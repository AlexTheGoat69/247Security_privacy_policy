# 24/7 Security Privacy Policy

**Last updated: October 21, 2026**

This policy explains what data the 24/7 Security Discord app ("24/7 Security", "we") collects, why, how long we keep it, and how to have it deleted. 24/7 Security is run by **pistolswap** on Discord, who is responsible for this data.

## What we collect

1. **Server settings:** your server ID and the settings your admins configure, including automod and security rules, log channels, roles, permissions, tags, and scheduled messages.
2. **Moderation records:** for each warn, timeout, kick, ban, or role removal, we store the server ID, the member's user ID, the moderator's user ID and username, the action, the reason, and the time.
3. **Violation counters:** the server ID, user ID, rule triggered, count, and time, used to enforce limits such as "3 violations in 60 seconds".
4. **Temporary spam data:** message IDs and counters, which expire automatically when your server's configured time window ends.

**We never store message content.** Messages are checked in memory against your server's automod rules and then discarded right away. We do not collect emails, IP addresses, DMs, or member lists.

## How we use it

We use this data only to run the bot's moderation and server features. We do not sell it, use it for advertising, or use it to train AI.

Where the GDPR applies, our legal basis is legitimate interest: keeping servers safe, which is the service the server's admins chose to install.

The bot can automatically warn, timeout, kick, or ban members. It does this only according to rules your server's admins set up, and those admins can reverse any action.

## Storage and sharing

Data is stored on OVHcloud servers in Canada, protected by passwords and firewall rules. If you are in the EU or UK, your data is transferred to Canada, which the EU recognizes as providing adequate data protection. We share data only with Discord, since the bot runs on its platform, with OVHcloud as our hosting provider, or where the law requires it.

## How long we keep it

1. Temporary spam data expires automatically.
2. Everything else is kept while the bot is in your server.
3. If the bot is removed from a server, all of that server's data is permanently deleted 30 days later. If the bot is added back within 30 days, the deletion is cancelled.
4. A server owner can ask us to delete all of their server's data at any time.

## Your rights

You can ask to see, correct, or delete data linked to your user ID or your server. You can also object to or ask us to limit how we use it, or ask for a copy in a portable format. We reply within 28 days.

We may keep moderation records (warns, bans, timeouts, and their reasons) after a deletion request while the server that issued them still uses the bot. Servers need this history to enforce their rules, review appeals, and stop members from resetting their record. If we keep anything, we will tell you why. The server owner can ask us to delete these records at any time.

If you are not satisfied with our answer, you can complain to the Office of the Privacy Commissioner of Canada or, in the EU or UK, to your local data protection authority.
